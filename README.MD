## LightGBM for Information Retrieval

This project was developed for the Information Retrieval course in the Computer Science master's degree program at the University of Pisa.

The goal is to read and understand the techniques presented in a research paper, then run experiments to verify selected assumptions, properties, and conclusions.

## Paper

Guolin Ke, Qi Meng, Thomas Finley, Taifeng Wang, Wei Chen, Weidong Ma, Qiwei Ye, and Tie-Yan Liu. 2017. *LightGBM: A Highly Efficient Gradient Boosting Decision Tree.* NeurIPS.

- [Paper](https://proceedings.neurips.cc/paper_files/paper/2017/file/6449f44a102fde848669bdd9eb6b76fa-Paper.pdf)
- [LightGBM repository](https://github.com/lightgbm-org/LightGBM)

## Dataset

The experiments use **MSLR-WEB10K**, a Microsoft Research dataset for learning to rank.

- [Dataset information and download](https://www.microsoft.com/en-us/research/project/mslr/)
